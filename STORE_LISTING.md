# Chrome Web Store listing, 1.3.1 draft

## Name
YouTube Transcript Reader

## Short description
Read, search, copy and download YouTube transcripts. Click timestamps to jump to the matching moment.

## Description
Read available YouTube captions beside the video.

- Search transcript text and jump to a matching timestamp.
- Copy the full transcript or just your search results.
- Download a UTF-8 text file, with or without timestamps.
- Switch between text and a timeline that follows playback.
- Keep the panel collapsed for quick copying.
- Use YouTube's light or dark theme and keyboard controls.

No extension account, AI subscription or developer-owned server is required. Transcript processing happens in your browser. Caption availability and requests to YouTube remain controlled by YouTube. The extension cannot create missing captions or bypass restricted content.
