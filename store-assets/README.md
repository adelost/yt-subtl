# Store assets

- `screenshot-1-timeline.png` and `screenshot-2-search-dark.png`: actual 1280x800 browser captures of version 1.3.2 on NASA ScienceCasts "Cool Science on the International Space Station" (CjjNRUSX348, Creative Commons Attribution on YouTube), light and YouTube's own dark theme. YouTube's recommendations, ad slots and the paused play button were hidden in the capture. The extension UI is unchanged.
- `small-promo-440x280.png`, `marquee-promo-1400x560.png`: flat promo tiles from 2026-10-15 with the store name, the speech-bubble icon and, in the marquee, an unedited crop of the panel from `screenshot-1-timeline.png`.
- `screenshot-1280x800.png`: a hand-rendered July illustration, not a browser screenshot. Do not use it.
- `store-icon-128.png`: the extension icon, the speech bubble from `src/static/icon.svg` (chosen 2026-10-15), same file as `src/static/icon128.png`.
